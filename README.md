# 《刹不住的境界》

> 后排萃浓缩，前排踩空气。

一个单文件 HTML5 恶搞小游戏：驾驶「断界 V八百」从 100 km/h 急刹，看看踏板支架会不会「咯嚓」。踏板断了就用 P 挡、手刹、冰箱降落伞、咖啡反推和乘客脚刹自救。

**在线试玩：** https://zmgid.github.io/brake-game/

- 纯前端、离线可玩、无任何外部依赖（直接打开 `index.html` 即可）
- 支持手机触屏与电脑键盘（空格 = 刹车，1-5 / F = 应急道具，Enter = 开始）
